Veterinary Education & Animal Care - static website

How to use
1. Unzip the folder.
2. Open index.html in any browser (no server, database or build step needed).
3. To publish, upload the whole folder to any static host (GitHub Pages, Netlify, etc.).

Files
index.html        Page shell
css/style.css     All styling
js/main.js        All content, navigation, search, tabs and slideshow
assets/logo/      AVC logo (replace avc-logo.png to change it)

Notes
- Page navigation uses #/ routes, so refresh and the back button work on any static host.
- Poppins, Playfair Display and Cinzel load from Google Fonts (internet needed for the fonts; fallbacks are used offline).
- Educational content is general information and must be reviewed by a qualified veterinarian before public use.
- Institution addresses, phones and emails are shown as 'Information not available' until verified from official websites.
